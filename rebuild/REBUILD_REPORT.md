# B-score 重建报告

日期：2026-10-22　目标：在源码丢失后重建 CB 信号与看板刷新链路

## 一、结论先说

**管线能重建，信号不能忠实复现。**

- 数据源、标的池、指标定义这些「口径」已经反推到能对上原看板（见 §2）；
- 但 CB 的核心是「历史分位」，原实现用的是 **2005 年起**的 expanding percentile，
  而目前能免费拿到的全市场逐日估值只到 **2018-01**；
- 用 2018 起的分位重算，2026-10-09~16 这 6 天的 CB 与原值偏差 **−0.204 ~ +0.030**，
  散布 0.10~0.17，而两条建仓阈值只差 0.05（0.75 / 0.80）——**偏差足以让买卖信号错位**。

因此本文交付的是：可复现的数据管线 + 已确认口径 + 明确的差距量，不是一个可以直接替换的 CB。

## 二、已反推并验证的口径

数据源：东方财富 `RPT_VALUEANALYSIS_DET`（逐股逐日 PB_MRQ + 总市值），
每日约 5577 条，单日 6 页。标的池与指标用 2026-10-16 这天的看板读数做靶子：

| 指标 | 原看板 | 复算（全市场） | 复算（剔除金融/ST） | 判定 |
|---|---|---|---|---|
| 有效样本 | 5269 只 | 5523 | **5244** | ✅ 剔除口径 |
| 破净率 | 7.2% | 8.53% | **7.15%** | ✅ 剔除口径 |
| 加权 PB | 2.25 | 1.71 | 2.35 | ⚠ 差 4.5%，疑为少数股东权益口径 |
| 全市场 PB | 3.82 | **3.8115**（去极值均值，PB≤50 截断） | 3.8013 | ✅ 去极值均值 |
| BM 中位数 | 0.397 | **0.397908** = 1/median(PB) | 0.392388 | ✅ 全市场 |

两条**可确定**的关键事实：

1. **BM 中位数 = 1 / median(全市场 PB)** —— 复算 0.397908，看板 0.397，误差 0.02%。
2. **CB = (BM 便宜度分位 + PB 便宜分位) / 2** —— 看板 0.559 = (0.637 + 0.481)/2，完全吻合。

看板「有效样本」一行的说明原文就是「剔除金融/ST/停牌」，与复算的 5244 只一致，
这也直接确认了标的池规则。

## 五、若强行用 2018 口径，会发生什么

按复算序列统计建仓阈值的触发频率：

| 条件 | 天数占比 |
|---|---|
| CB ≥ 0.70 | 32.0% |
| CB ≥ 0.75（建仓） | **27.1%** |
| CB ≥ 0.80（满仓） | 22.1% |
| PB 分位 ≤ 0.15（清仓） | 11.5% |
| PB 分位 ≤ 0.25（减仓） | 19.2% |

分年看 CB ≥ 0.75：2018 年 **75.7%**、2021 年 **0%**、2024 年 **81.8%**、2026 年 **0%**。

「建仓」信号有 27% 的交易日成立，且年度间从 0% 跳到 82% —— 这不是一个可用的择时信号，
而是短窗口 expanding percentile 的结构性伪影（早年历史样本太少，排名抖动极大）。

## 六、三条路

| 方案 | 做法 | 代价 | 结果 |
|---|---|---|---|
| **A. 换长历史数据源** | 用理杏仁 / 聚宽 / 米筐 / iFinD 等能取 2005 起全市场估值的源，重跑 `build_panel` 与 `compute_cb` | 需要账号（多为付费） | 有机会忠实复现，是唯一能真正"恢复"的路径 |
| **B. 接受新口径并重标定** | 承认 2018 起的分位，按分位数重设阈值（如 CB ≥ 0.95 建仓），看板明确标注「口径已变更」 | 无 | 得到一个**新信号**，不是原来那个；历史可比性为零 |
| **C. 停用信号线** | 看板转静态存档，不再自动刷新 | 无 | 不会再被错误信号误导 |

## 阈值怎么定的

不是拍脑袋，用原看板第五章的真实信号历史做参照。原文记录 7 次买入信号
（2008-10、2012-11、2018-08、2019-08、2022-04、2023-10、2025-01），
其中 5 次落在可用数据窗口内，年均约 0.57 次。

在 v2 序列上按「触发频次相当」标定：

| 阈值 | 触发次数 | 年均 |
|---|---|---|
| 0.82 | 6 | 0.80 |
| **0.85** | **5** | **0.67** ← 采用 |
| 0.88 | 4 | 0.53 |
| 0.92 | 2 | 0.27 ← 满仓档 |

同时试过 3 种分位算法（expanding 加最小样本 250/500/750、滚动 750/1250/1750），
**最多次只能命中原信号 5 次中的 3 次**——2018-08 与 2019-08 在任何方案下都无法复现，
因为那两次的「便宜」是相对 2005–2017 的昂贵期而言，而我们没有那段历史。
**所以 v2 的触发时点与原版不同，这是已知且不可消除的差异。**
